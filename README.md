# Portfolio Website

A personal portfolio website for **Abhinav Tomar**, built with **HTML, CSS and JavaScript**. It introduces me, lists my skills and shows the projects I work on.

## Sections

- **Navigation bar** with the logo and links to Home, About, Contact and Services
- **Hero section** with the greeting "Hi, My name is Abhinav Tomar", an animated typing line, and **Resume** and **View GitHub** buttons, next to a developer illustration
- **Skills** grouped by category:
  - Languages: HTML5, CSS, JavaScript
  - Frontend Frameworks: Bootstrap
  - Backend Frameworks: Node.js
  - Version Control: Git, GitHub
- **Projects** list: AI Chatbot, Social Media App, Library Management System
- **Footer** with copyright text

## Features

- Typing animation in the hero section using **Typed.js**
- Clean, sectioned layout with dividers between the hero, skills and projects
- Custom fonts from Google Fonts (Figtree, Jost, Montserrat and Noto Sans)
- Logo and icons for the Skills and Projects headings

## Tech Stack

- HTML5
- CSS3
- JavaScript
- [Typed.js](https://github.com/mattboldt/typed.js) for the typing effect
- Google Fonts

## How to View

Open `index.html` in your browser. An internet connection is needed because Typed.js and the fonts load from a CDN.
